# VC Farm

Админ-бот управляет подключёнными Telegram-аккаунтами: отправляет `ферма` в `@VirusikChat`, нажимает «Собрать», а также ведёт отдельный бонусный цикл.

> Используйте только аккаунты, которыми вы вправе управлять, и убедитесь, что автоматизация разрешена правилами Telegram и целевого чата. Частые или массовые однотипные действия могут привести к ограничениям аккаунтов.

## Установка

1. Установите Python 3.11 или новее.
2. Создайте Telegram-бота через `@BotFather`.
3. Получите `api_id` и `api_hash` приложения на `my.telegram.org`.
4. Подготовьте окружение:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
```

5. Запишите значения в `.env`. В `ADMIN_IDS` указываются числовые Telegram ID администраторов через запятую. Сгенерированный ключ вставьте в `SESSION_SECRET` и не меняйте после добавления аккаунтов.
6. Запустите:

```powershell
python main.py
```

Откройте управляющего бота, отправьте `/start`, нажмите «Аккаунты» → «Добавить аккаунт». Номер и облачный пароль вводятся текстом, код подтверждения — экранными кнопками. Остальное управление выполняется кнопками.

## Как работает расписание

- Новый включённый аккаунт запускается после `STARTUP_DELAY_SECONDS`.
- Командные циклы `ферма` и `ларек` отключены (`FARM_ENABLED=false`, `STALL_ENABLED=false`).
- Между аккаунтами выдерживается `BETWEEN_ACCOUNTS_SECONDS`, чтобы они не срабатывали одновременно.
- Новая сессия получает обязательную задержку 1 час перед первым действием.
- Цикл «ларек» отправляет `ларек` раз в 30 часов и нажимает кнопку «Собрать».
- Бонусный цикл отправляет `б` в `BONUS_CHAT`, нажимает кнопку «Бонус» и повторяет успешный запуск раз в 24 часа; если кнопка не найдена, повторяет проверку через 30 минут.
- При `FloodWait` или явном спам-ограничении аккаунт автоматически переводится в карантин и уведомляет администраторов. Автоматического обхода ограничений и самовольного возобновления нет — после проверки администратор может включить аккаунт вручную.
- Ошибка одного аккаунта не останавливает остальные; результат виден в карточке и отправляется администраторам.
- Бот должен работать постоянно. После перезапуска сохранённое время следующего запуска не теряется.

Сессии аккаунтов хранятся в `data/farm.db` только в зашифрованном виде. Файл `.env`, база и каталог `data` исключены из Git.
